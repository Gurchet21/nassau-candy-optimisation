# 🏭 Factory Reallocation & Shipping Optimization System
## Nassau Candy Distributor

An intelligent analytics dashboard that analyzes distribution data to recommend optimal factory locations and shipping strategies for maximum profitability and efficiency.

## ✨ Key Features
- 🗺️ Geographic demand & delivery time mapping
- 🚚 Shipping mode profitability analysis
- 🏭 Data-driven factory placement scoring
- 💰 ROI & payback period calculator
- ✅ Exportable prioritized action plan
